📖 탑툰 다운로드 — 사용 안내

빠른 시작

  1. 쿠키 주입 — toptoon.com 로그인 → Cookie-Editor 확장으로 .toptoon.com 도메인 쿠키를 JSON export → 설정 > 일반 > 탑툰 쿠키에 붙여넣기. 필수 쿠키는 PHPSESSID 하나뿐이며, 없으면 즉시 인증 오류로 거부됩니다.
  2. 경로/작품 등록 — 다운로드 경로 지정 → 체크할 작품에 한 줄에 하나씩(제목·URL·comic_id·idx 모두 인식), 또는 연재목록 메뉴에서 찾아 "설정에 추가"로 채우기.
  3. 실행 — 설정 저장 → 쿠키 검증 → 즉시 실행 또는 자동 탭에서 스케줄러 등록.

도구 버튼 (설정 탭 상단)

버튼동작
즉시 실행스케줄 무시하고 자동 다운로드 1회 실행 (백그라운드로 즉시 시작 — "진행 상황"에서 확인).
쿠키 검증현재 쿠키의 세션 로그인 상태와 성인인증 상태를 각각 확인.

성인인증은 세션과 별개입니다

탑툰 인증은 두 축입니다 — 세션 로그인(PHPSESSID 등)과 성인인증(showAdult, UAR, C_K)입니다. 둘 중 하나만 끊겨도 증상이 다릅니다: 세션만 살아있고 성인인증이 없으면 세션은 정상인데 성인 작품만 열람이 막힙니다. "쿠키 검증" 버튼은 두 결과를 각각 표시하니, 성인 작품을 받다가 실패가 늘면 이 배지부터 확인하세요.

download_scope 값의 의미

값의미
free무료 회차만 받습니다.
free_owned (기본값)무료 + 소장(구매) 회차까지 받습니다.
free_owned_rental무료 + 소장 + 대여 전용 회차까지 받습니다(opt-in).
⚠ 대여 회차 주의: 대여는 기간제 상품입니다. free_owned_rental 로 받은 대여 전용 회차를 영구 보관하는 것은 대여 계약(구매 범위)을 넘어설 수 있습니다. 필요할 때만 켜고, 대여 기간이 끝나기 전에 직접 열람 가능 여부를 스스로 확인하세요.

레이트리밋(sleep_image/sleep_episode) 값을 낮추면 안 되는 이유

탑툰은 핑거프린트 기반 회원 차단 엔드포인트(setFingerprintMemberAndMemberBlock 등)를 운영합니다. 이 플러그인은 그 탐지를 위조·회피하지 않고, 정상 브라우저와 같은 순서·속도로만 요청합니다. (요청 자체는 curl_cffi 로 브라우저와 동일한 TLS 지문을 써서 보냅니다 — 평범한 파이썬 HTTP 클라이언트 지문으로는 정상 회원 요청조차 막히기 때문이며, 차단 판정을 우회하려는 것이 아니라 본인 세션이 브라우저와 같은 모양으로 도달하게 하려는 것입니다.) 즉 사이트가 이상 트래픽으로 판단하지 않게 막아주는 유일한 방어선이 sleep_image(이미지 간 대기, 기본 0.15초)와 sleep_episode(회차 간 대기, 기본 2.0초)입니다. 이 값을 낮추면 본인 탑툰 계정이 통째로 차단될 수 있습니다. 다운로드가 느리게 느껴져도 기본값 아래로 낮추지 마세요.

수동 다운로드 "분석"이 오래 걸릴 수 있습니다

분석 버튼은 회차 목록을 얻기 위해 뷰어 진입을 최대 5회까지 순차로 시도할 수 있고, 각 시도가 location_check(최대 15초) + open_viewer(최대 30초) + 시도 사이 대기(2초)로 이뤄져 최악의 경우 약 4분(233초)까지 걸릴 수 있습니다. 화면에는 분석 중 안내가 뜨고 버튼이 잠깐 비활성화되니, 진행 중에는 다시 누르지 말고 기다려주세요. 응답이 끊겨 보여도(프록시 타임아웃 등) 서버 쪽 분석은 계속 진행 중일 수 있으니, 잠시 후 다시 분석을 시도하세요.

또한 연재목록/수동 다운로드가 쓰는 전체 작품 카탈로그(약 6MB, 2,034건)가 아직 캐시에 없으면 분석/목록 조회가 즉시 "카탈로그 준비 중"을 돌려주고 백그라운드로 채우기 시작합니다. 이 경우 몇 초~수십 초 후 다시 시도하면 됩니다(화면이 자동으로 재시도하는 경우도 있습니다).

이 플러그인은 본인이 정당하게 접근 권한을 가진 콘텐츠를 개인 보관 목적으로 내려받는 용도입니다. 탑툰 이용약관과 저작권법을 준수해 사용하세요.
