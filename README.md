# 탑툰 회차 다운로드

계정이 열람 권한을 가진 회차를 개인 라이브러리로 보관하는 FlaskFarm 플러그인.

- 무료 회차와 소장(구매) 회차를 받는다. 대여(rent) 회차는 기간제 상품이라
  기본값에서 제외되며 설정에서 명시적으로 켜야 한다.
- 이미지 서명(`key=`) 역산과 뷰어 보호 무력화는 하지 않는다. 서버가 내려준
  URL만 소비한다.
- 핑거프린트 **위조·회피**는 하지 않는다. 탑툰의 회원 차단 대응은 정상
  브라우저와 같은 순서·속도로 요청하는 것이지 탐지를 속이는 것이 아니다.
  - 단, 요청 자체는 `curl_cffi` 로 브라우저와 동일한 TLS(JA3/JA4) 지문을 써서
    보낸다. 평범한 파이썬 HTTP 클라이언트의 지문으로는 정상 회원 요청조차
    막히기 때문이며, 이건 의도된 의존성이다. 차단 판정을 우회하려는 것이
    아니라 사용자 본인 세션이 브라우저와 같은 모양으로 도달하게 하는 것이다.
- 코인 자동 결제는 하지 않는다. 미구매 회차를 자동으로 사지 않는다.
- 탑툰은 과속 시 계정을 차단한다. 설정의 대기 시간을 낮추지 말 것.
